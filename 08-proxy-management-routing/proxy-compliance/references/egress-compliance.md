# Egress Compliance

Register: provider ToS (allowed use, geo, rate), target ToS/robots per flow, data laws (GDPR/CCPA/PIPL as applicable), sanctions and export controls. Map each to router/queue controls; deny by default; version everything.

Basis docs per flow: purpose, lawful basis, scope (URLs, fields, volume, geo), retention, owner, review date. Legal sign-off for personal data, login-walled, or disputed targets. No doc, no traffic.

Enforcement: block lists for prohibited targets; geo fences per license; allow lists for sensitive programs; alerts on denied attempts (possible intent signal). Monthly audits: decisions sampled vs policy, exceptions with owners and dates.

Violations: contain (pause flow, preserve logs), assess (scope, cause), disclose per contract/policy, remediate (controls + training), postmortem. Drill yearly with legal observing.
