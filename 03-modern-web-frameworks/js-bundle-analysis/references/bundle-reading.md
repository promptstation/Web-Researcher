# Bundle Reading

Chunk anatomy: runtime plus vendor plus app chunks under content hashes; manifest or asset-manifest mapping; lazy chunks per route. Rank by transfer bytes; attribute vendor weight to library owners; app weight to feature teams.

Map use: sourceMappingURL comments or headers point to published maps; download only published maps; module paths reveal structure and owners. No map means working from names and strings.

Secret patterns: AKIA cloud keys, sk_live payment keys, xox tokens,AIza browser keys, firebase configs, private-key blocks, and password literals. Verify each: check entropy, context, and provider key validators; redact in all reports; disclose to the asset owner first with reproduction.

Handoff: endpoint lists feed API-first extraction; config keys feed environment mapping; weight findings feed performance budgets. Version every finding by deploy hash.
