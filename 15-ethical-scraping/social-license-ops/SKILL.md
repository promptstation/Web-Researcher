# Social License Ops

Be welcomed, not tolerated. You read norms before collecting, give back real value, offer opt-outs that actually work, publish your practices, and repair missteps with amends — tracking license like revenue.

Optimize simultaneously for:

- read norms
- real reciprocity
- working opt-outs
- open practices
- repaired trust

No means no: opt-outs honored fully and fast, no dark retention.

## Use Cases

### New community

Trigger: user says 'scrape forum X' or 'new source'

Steps:

1. Read norms
2. Introduce + ask
3. Reciprocate
4. Opt-out live

Result: Welcomed collection.

### Opt-out wave

Trigger: user says 'many opt-outs' or 'backlash'

Steps:

1. Honor all fast
2. Listen + adapt
3. Amends apt
4. Re-earn slowly

Result: Respected exit/return.

### License audit

Trigger: user says 'are we welcome' or 'reputation check'

Steps:

1. Survey signals
2. Score license
3. Fix gaps
4. Report

Result: Known standing.

Ask yourself before starting:

- What is the smallest verifiable outcome the user needs?
- What evidence will prove the result is correct?
- Which failures are most likely, and how will each be detected?
- What scope, budget, or policy constraints apply?
- What artifact must remain for audit or reuse?

## Core Output Requirements

Every delivery with this skill must include:

- Norm notes
- Reciprocity plan
- Opt-out log
- Transparency page
- Liaison contacts
- Grievance log
- Amends record
- License score

Never extract without return or dishonor opt-outs in letter or spirit.

## Phase 1 — Read Norms

Robots, ToS, culture, history.

Score with `scripts/license_check.py`.

Ask before assuming.

## Phase 2 — Give First

Attribution, traffic, data, support, fees.

Sized to value taken.

Documented publicly.

## Phase 3 — Opt-Out Real

Easy discovery + one action.

Honored <72h incl. derivatives.

Confirmed + logged.

## Phase 4 — Stay Welcome

Liaison + grievance live.

License scored quarterly.

Amends fast on harm.

## Troubleshooting

### Silent resentment

Cause: No liaison channel

Fix:

1. Open channel
2. Ask sentiment
3. Adapt visibly
4. Report back

### Opt-out theater

Cause: Derivatives retained

Fix:

1. Map derivatives
2. Delete truly
3. Verify
4. Apologize + fix

### Reciprocity mismatch

Cause: Token gestures

Fix:

1. Size fairly
2. Ask what helps
3. Deliver + show
4. Sustain

## Decision Heuristic

Before adding complexity, ask:

1. What outcome requires this step?
2. What evidence justifies it?
3. What happens when it fails?
4. What is the cheaper alternative?
5. What proves quality did not regress?
6. What must be logged for audit?
7. What is the rollback plan?

If the main justification is "more", prove the outcome needs it first.

## Anti-Patterns

Avoid extract-only ops; norm-blind collecting; theater opt-outs; liaison-free communities; amends-free harm; score-free license.
