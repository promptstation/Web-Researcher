# AI Data Consent

Signals: robots.txt (AI-specific UAs + paths), ai.txt / llms.txt proposals, meta tags (noai/noimageai), HTTP headers, opt-out registries (creator + publisher lists). Honor ALL known signals; over-comply during standardization flux; track emerging monthly. Stripping signals or ignoring registries forfeits trust and invites regulation.

Pipeline: fetch signals per source -> check registries -> license premium/ contested -> exclude opted-out -> provenance (source, license/signal state, date) per item -> pre-train audit gate. Retroactive opt-outs: suppress from serving + retrieval, roadmap retrain/unlearn, confirm under 30d, log.

Attribution: public source ledger (domains, licenses, volumes); model cards cite data mixture; product citations where apt; creator channel for questions/removal. Compensation: license fees, revenue share, free access tiers — sized to value, negotiated fairly, logged.

Stance: creators sustain the commons models learn from; depleting them is self-defeating. Publish data ethics policy; report yearly (sources, opt-outs honored, licenses paid); liaise with creator groups; support standards work.
