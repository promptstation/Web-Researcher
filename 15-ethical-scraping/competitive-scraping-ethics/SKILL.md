# Competitive Scraping Ethics

Win without poison. You license before scraping, ban sabotage absolutely, respect makers even as rivals, attribute value, and exit cleanly when asked or outbid — with leadership backing every line.

Optimize simultaneously for:

- licensed feeds
- zero sabotage
- respected rivals
- paid value
- clean exits

Sabotage and deception are firing offenses; licensing beats scraping on contested ground.

## Use Cases

### Price intel

Trigger: user says 'track competitor prices' or 'market data'

Steps:

1. License first?
2. Scrape polite if open
3. Attribute + compensate
4. Exit if asked

Result: Fair intel.

### Dark ask

Trigger: user says 'fake reviews' or 'hammer their site'

Steps:

1. Refuse written
2. Explain + alt
3. Escalate
4. Protect refuser

Result: Sabotage refused.

### Deal over scrape

Trigger: user says 'they sell a feed' or 'partner?'

Steps:

1. Price build-vs-buy
2. Negotiate
3. Migrate
4. Relationship kept

Result: Licensed peace.

Ask yourself before starting:

- What is the smallest verifiable outcome the user needs?
- What evidence will prove the result is correct?
- Which failures are most likely, and how will each be detected?
- What scope, budget, or policy constraints apply?
- What artifact must remain for audit or reuse?

## Troubleshooting

### License too dear

Cause: Monopoly pricing

Fix:

1. Negotiate hard
2. Narrow scope
3. Build open alt
4. Accept cost or skip

### Rival scrapes you

Cause: Asymmetric norms

Fix:

1. Technical + legal + offer feed
2. No retaliation hacks
3. Compete on product
4. Log all

### Exit drags

Cause: Sunk pipeline

Fix:

1. Wind-down dated
2. Delete confirmed
3. Migrate team
4. Close file

## Decision Heuristic

Before adding complexity, ask:

1. What outcome requires this step?
2. What evidence justifies it?
3. What happens when it fails?
4. What is the cheaper alternative?
5. What proves quality did not regress?
6. What must be logged for audit?
7. What is the rollback plan?

If the main justification is "more", prove the outcome needs it first.

## Anti-Patterns

Avoid license-skipping; rival-rate-hammering; identity games; free-riding feeds; sabotage winks; exit-dragging.
