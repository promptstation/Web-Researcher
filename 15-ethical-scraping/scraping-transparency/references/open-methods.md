# Open Methods

Methods docs: sources (which sites/feeds, why), tools (stack, versions), politeness (rates, robots, windows), dates/versions, processing (cleaning, dedupe, filters), QA (evals, audits). Generated from pipeline metadata where possible; readable by non-team; versioned with data releases.

Limits: coverage gaps, known biases, freshness lag, error rates, sensitive exclusions — prominent placement, plain language, updated per release. Marketing never softens limits; authors sign off on claims.

Scrutiny: public contact with SLA; repro assets (code, samples, seeds); query log with dated responses; external audit yearly-ish with published summary. Corrections: visible notices (what, when, impact), versioned data (diffs), user notification for material, postmortem into checks. Silent fixes are trust violations.

Reports: quarterly transparency (volumes, sources, complaints, corrections, opt-outs, audits) published; trends discussed; commitments tracked. Sunlight is the QA that never sleeps.
