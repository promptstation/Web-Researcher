# Clean Room

Clean-room basics: observe behavior and interfaces; write specs describing what, not how; implement solely from specs; keep observation logs separate from implementation. Never paste vendor code into notes or products.

Scope discipline: endpoints, params, formats, and protocols are interface territory; UI text, artwork, and implementation algorithms need extra care. Terms may add contractual limits beyond statute; read them and brief counsel on conflicts.

Documentation: date every observation; cite lawful source (owned traffic, public bundles, permissioned testing); version specs; test compatibility with matrices. Permission trails beat after-the-fact memos.

This skill is process guidance, not legal advice. Gray areas pause for qualified counsel.
