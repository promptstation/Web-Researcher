# DSAR Runbook

Intake: single channel + backup; log receipt timestamp (SLA starts); acknowledge in 3 days; case per request in tracker with due date (1 month GDPR / 45d CCPA / 15d LGPD-ish, extend lawfully once with notice). Types: access, erasure, rectification, portability, restriction, objection.

Verify: proportionate (account login < ID docs < attested for sensitive); never build new PII stores to verify; document method; agents need authorization proof. Search: inventory-driven runbooks per system incl. backups, logs, analytics, vendors; evidence (queries run + hits) filed; third-party data flagged for redaction.

Respond: portable formats for portability; plain language; include what was found, what was done, what kept + basis; redact third parties and privileged; two-eye review; deliver securely. Refusals (manifestly unfounded, excessive, exemptions): reasoned memo + appeal info, counsel-reviewed.

SLA ops: dashboard (open, due-7d, overdue=0); vendor SLAs contracted; postmortem every miss; quarterly drill with synthetic subject. Volume: runbook -> assisted -> automated search with human QA.
