# Incident Ops

Roles: commander decides and timestamps; comms updates stakeholders; fix executes playbooks; scribe keeps the timeline. One commander, no committees mid-incident. Declare early; downgrade cheaply.

Containment ladder: freeze new leases, park affected, diagnose scope, canary one probe, ramp staged 1-5-25-100 on green windows, abort to park on re-trip. Diagnose while contained, never while flooding.

Signatures: wave is multi-domain challenge spike; decay is gradual pool erosion; single-domain is local policy or deploy. Each maps to a playbook page with first three commands.

Postmortem: timeline, impact, causes (no blame), what worked, prevention items with owners and dates. File in 48h; track items to shipped; share lessons fleet-wide.
