# Checklists (copy into delivery)

## Cookies

- [ ] Every cookie inventoried.
- [ ] Secure plus HttpOnly on sessions.
- [ ] SameSite minimal and correct.
- [ ] Expiries minimal.

## Storage

- [ ] Usage versus quota measured.
- [ ] Tiers classified by fitness.
- [ ] Eviction rules defined.
- [ ] Migrations versioned.

## Safety

- [ ] Selective clear tested.
- [ ] Partition behavior verified.
- [ ] Secrets swept from wrong tiers.
- [ ] Logs redacted.
