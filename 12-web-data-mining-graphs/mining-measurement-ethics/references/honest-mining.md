# Honest Mining

Coverage: define target population (all product pages? news since 2020?); diff known vs crawled by segment (source, geo, time, category); explain every gap (blocked, js, trap, budget); fix or disclose — never silently generalize.

Bias: selection bias (who is missing), algorithmic bias (who ranks/scored lower), temporal bias (stale segments); measure with reference stats; report with uncertainty; weight or stratify where valid; disclose residuals.

Boundaries: consent for personal/sensitive mining; ToS honored; PII minimized and redacted; vulnerable-population mining ethics-reviewed; dual-use findings handled with care (aggregate, delay, or withhold per review).

Publishing: method doc (sources, code version, seeds, dates), limit statement (what claims do NOT support), repro package (code + data sample + environment), correction policy (log, notify, fix). Review before publish; correct openly after.
