# Discovery Mining

Let sites guide discovery. You parse sitemaps at scale, mine feeds for freshness, read robots right, verify lastmod before trusting, and reconcile discovered vs crawled until coverage is proven.

Optimize simultaneously for:

- parsed maps
- mined feeds
- verified hints
- reconciled coverage
- fresh loops

Hints verified before scheduling; discovery polite like crawling.

## Use Cases

### News freshness

Trigger: user says 'new articles fast' or 'feed-driven'

Steps:

1. Mine feeds
2. Verify + fetch
3. Track lag
4. Loop tight

Result: Minutes-fresh news.

### Shop catalog

Trigger: user says 'all products' or 'sitemap crawl'

Steps:

1. Parse sitemaps
2. Reconcile vs fetched
3. Triage gaps
4. Prove complete

Result: Complete catalog.

### Coverage audit

Trigger: user says 'what did we miss' or 'prove coverage'

Steps:

1. Union sources
2. Diff vs crawled
3. Explain gaps
4. File report

Result: Audited coverage.

Ask yourself before starting:

- What is the smallest verifiable outcome the user needs?
- What evidence will prove the result is correct?
- Which failures are most likely, and how will each be detected?
- What scope, budget, or policy constraints apply?
- What artifact must remain for audit or reuse?

## Core Output Requirements

Every delivery with this skill must include:

- Sitemap inventory
- Feed list
- Parse logs
- Hint verification
- Coverage math
- Gap list
- Lag metrics
- Refresh schedule

Never trust lastmod blindly or claim coverage without reconciliation.

## Phase 1 — Parse Maps

Indexes + URL sets, namespaces right.

Run `scripts/sitemap_mine.py --url MAP` per sitemap.

Inventory counts per map.

## Phase 2 — Mine Feeds

Poll etag-aware; extract URLs.

Track per-item lag.

Alert on feed death.

## Phase 3 — Verify Hints

Sample lastmod vs actual change.

Trust score per source.

Schedule by verified hints.

## Phase 4 — Reconcile

Discovered vs crawled diff.

Triage gaps with reasons.

File coverage report.

## Troubleshooting

### Sitemap lies

Cause: Stale or autogenerated junk

Fix:

1. Verify sampled
2. Score trust
3. Blend crawl discovery
4. Report honestly

### Feed gaps

Cause: Partial feeds or death

Fix:

1. Detect death fast
2. Backfill via sitemap
3. Alert owner
4. Dual-source

### Coverage stuck

Cause: JS-only or blocked URLs

Fix:

1. Render path
2. Access review
3. Document excludes
4. Reconcile rest

## Decision Heuristic

Before adding complexity, ask:

1. What outcome requires this step?
2. What evidence justifies it?
3. What happens when it fails?
4. What is the cheaper alternative?
5. What proves quality did not regress?
6. What must be logged for audit?
7. What is the rollback plan?

If the main justification is "more", prove the outcome needs it first.

## Anti-Patterns

Avoid namespace-blind parsing; lastmod-blind trust; feed-death blindness; robots-guessing; reconciliation-free claims; impolite discovery.
