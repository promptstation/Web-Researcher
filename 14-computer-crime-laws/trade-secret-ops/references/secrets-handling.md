# Secrets Handling

Trade secrets: information with economic value from secrecy + subject to reasonable measures (marking, access control, NDAs, training). Misappropriation: acquire/use/disclose via improper means or breaching duties. Scraped 'internal-only' docs, leaked creds/keys, insider-offered data = stop signs.

Finds protocol: stop use immediately; quarantine (isolate, no copies, no discussion beyond need-to-know); counsel same-day; follow delete/return/notify direction; memo facts + actions; block source pattern. Never publish 'for transparency' without counsel — that spreads harm and liability.

Guarding own: classify (public/internal/confidential/secret) with criteria; mark + gate + log; NDAs with staff/vendors/partners (scope, term, return); exit hygiene (revoke, remind, attest); reasonable measures audited yearly — unguarded 'secrets' are not secrets.

Training: tells (headers, watermarks, URL patterns like /internal/, robots-disallowed + sensitive), refusal scripts for offers, quarantine drills yearly. Praise clean-hands calls loudly.
