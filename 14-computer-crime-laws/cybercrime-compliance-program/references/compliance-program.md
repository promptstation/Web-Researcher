# Records Program

Risks: register 20+ (access, IP, contracts, circumvention, fraud, evidence, disclosure, cross-border, secrets) with likelihood x impact, owner, and treatment. Quarterly review; top-5 to leadership. Treatment: mitigate (controls), transfer (insurance/contracts), accept (signed), avoid (stop activity).

Controls: preventive (gates, allowlists, training), detective (monitoring, audits, attestations), corrective (playbooks, remediation, discipline) — mapped per risk with RACI and evidence. Control audits: design + operating effectiveness, sampled evidence, findings rated/owned/dated, verification of closure.

Training: tiers (all-hands yearly, role deep-dives, leadership briefings); tested (quizzes, phishing, tabletops); consequences for negligence; records kept. Culture: praise line-holding, protect whistleblowers, discipline willful violations fairly and visibly.

Reporting: quarterly pack (posture, top risks, findings aging, incidents, training completion, decisions needed); board minutes filed; external audit support calm via continuous evidence. Programs mature: ad-hoc -> managed -> measured -> adaptive.
