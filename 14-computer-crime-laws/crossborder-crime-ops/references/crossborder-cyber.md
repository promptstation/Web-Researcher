# Cross-border Cyber

Budapest Convention: harmonized cybercrime definitions + cooperation tools (expedited preservation ~90d, production orders, search/seizure, interception, MLA). Know parties per corridor; preservation requests route via 24/7 points fast; content production usually needs MLA/court. Non-parties: slower diplomatic paths.

Conflicts: US compulsion (CLOUD Act orders) vs EU blocking/GDPR, CN secrecy/security review, BR LGPD — memo competing duties, local counsel decides local exposure, MLAT/authority-to-authority preferred over direct foreign orders. Never silently violate either side; document the bind.

Localization: map per country (CN/IN/RU/VN strict-ish flavors; sectoral elsewhere); design residency (store/process/support inside), verify enforcement (no admin backdoors abroad), audit yearly. Transfers out need mechanisms + assessments.

Response sequencing: preserve everywhere first (fast, low-risk), counsel per jurisdiction in parallel, notify per earliest SLA then others phased, log one timeline. Corridor playbooks with contacts reviewed yearly; cross-border drill yearly. HQ never guesses local law.
