# Disclosure Requests

Vuln disclosure: private report first (scope, repro, impact, suggested fix); agreed timeline (45-90d typical, faster for exploited); vendor patch + credit; coordinated public detail after fix or deadline; CERT/CC for unresponsive; never weaponize, ransom, or dump recklessly. Safe harbor for good-faith research stated in policy.

Data requests: subpoenas (testimony/records, challengeable), warrants (search, court-issued, narrow scope), preservation letters (retain, do not produce yet), national-security/informal (counsel + verify, never phone-data). Intake: counsel-only, preserve immediately, clock deadlines, verify authenticity + jurisdiction + scope.

Response: challenge overbroad/privileged; produce exact valid scope with documented handoff; user notice unless barred by valid order (then delayed notice calendared); log (request, process, scope, production, notices) immutably. Transparency: aggregate counts published periodically.

Red lines: no data on informal asks; no bulk fishing without fight; privilege (counsel comms, work product) asserted; cross-border requests via MLAT/counsel, not direct foreign compulsion. Train intake teams; drill yearly.
